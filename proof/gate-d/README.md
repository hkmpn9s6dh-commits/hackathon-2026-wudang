# 闸 D · 尺子没成，先说清为什么

## 结论

**这一闸没走完，不是作品没过，是尺子不成立。** 不拿一张不成立的尺子给评委，也不自己给自己判过。

## 试过什么

`node scripts/gate-d.mjs` 抓了 6 张同级参考（故宫数字文物库、湖南博物院、国家博物馆、苏州博物馆、三星堆、teamLab），
连同本作品拼成 `sheet.png`（7 格，随机字母 A–G）。抓取全部成功，但拼出来的东西不能用：

1. **画幅不对等**：本作品是 9:16 竖屏作品画面；其余 6 张是 16:9 的**网站首页**（带导航、banner、活动角标）。
   混在一起排，评的是"谁家的网页做得好"，不是"谁的作品第一眼更抓人"。
2. **裁切把构图毁了**：为了统一成 3:2，两边都要裁；竖屏作品裁成 3:2 就只剩中间一条。
3. **不是"往届得奖作"**：数字武当杯是首届，没有往届。同级参考应该找**同类赛事的获奖作品整屏图**，
   而不是机构官网门面。
