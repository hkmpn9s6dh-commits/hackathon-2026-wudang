## 2. 一句话

按住吸气，云从七十二峰倒流上金顶；松手呼气，太极十三势一式落地。十三口气，一炁朝元。

## 3. 为什么是「呼吸」

- 太极的入门不是动作，是**呼吸**；游客在景区排队时最不缺的是站着不动的三十秒。
- 「按住—松手」是唯一一个**不需要教程、看一眼就会**的手势，而且它本身就是吸与呼。
- 十三势正好是十三口气。**有尽头**的互动才会被走完；走完才有「一炁朝元」这句话。

## 4. 演示脚本（60 秒，给评委）

| 秒 | 画面 | 说明 |
| --- | --- | --- |
| 0–6 | 纸、三层远山、金顶一线、一个道童站在岩上 | 一句话：这是武当，一个人，一口炁 |
| 6–14 | 按住不动：云向上收，人物抬臂，圈收紧 | 吸气；出现「掤 / 如捧一炁于胸前」 |
| 14–22 | 松手：云散回谷，人物落势 | 呼气；势名换成下一势 |
| 22–40 | 快进三口气 | 三势各不同：捋、挤、按 |
| 40–52 | 走满十三势 | 十三个点亮起 |
| 52–60 | 收势：朝元 / 一炁朝元 | 停在这一帧，可再来一遍 |

## 6. 明确不做

- 不做 3D、不做虚拟人动捕、不做语音合成：规则没有要求，做了就是拿完成度去赌。
- 不做账号、不做数据上报、不做支付：景区装置要的是「插上就能跑」。
- 不做多语言：赛道是国内文旅赛，先把中文做到位。
- 不做「一键生成」的 AI 拼贴：规范明确禁止，也过不了自己这一关。
