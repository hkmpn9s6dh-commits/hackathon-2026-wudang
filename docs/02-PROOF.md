## 4. 我特意验的几件小事

1. **短按不误触**：手指在屏上蹭一下不能算一势，否则排队时乱点会把十三势刷完。
2. **空格键**：装置侧常配键盘/遥控，键盘能玩才算真的能玩。
3. **减少动态**：景区有对光敏感的游客；`prefers-reduced-motion` 下动画减到零，但仍能推进。
4. **字体不靠系统**：评委机器上没装思源宋体，画面就垮了——所以字体随包。
5. **线上与本地同一套检查**：部署后的产物和本地 build 不是一回事，必须各跑一遍。

## 5. 没验到的（说在前面）

- **只在 Chromium 上验过**。Safari / Firefox 没跑；用到的都是标准 Canvas 2D 与 CSS，但没实证。
- **真机没上**：没在景区竖屏一体机、也没在低端安卓平板上跑过；帧率未知。
- **iOS 触摸**：用 Playwright 的 touch 模拟过，没有真机。
- **长时间挂机**：没有跑 24 小时看内存曲线；按现在的实现（一次性离屏 + 每帧 blit）风险低，但没测。
