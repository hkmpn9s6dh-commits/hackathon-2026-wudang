# 03 · 虚拟人「和」设定书

> 赛道四要求「数字文创作品及落地说明」；虚拟人设定本身就是可交付的文创内容。
> 本文是「和」的设定原件，可单独作为 IP 文档使用。

## 一、她是谁

**和**，武当山门下的少年道童，看山的。

不是神仙，也不是导游。她的工作只有一件：在金顶看着云，替上来的人数呼吸。
名字取「太和」——武当山旧名太和山，金顶的大殿就叫太和宫。

- 年龄：看不出。像十三四岁，也像很老。
- 性别：设定为「不强调」。称呼一律用「和」，不用她/他。
- 来历：不说。设定文档里只有一句「在山上很久了」。

## 二、性格与语气

- 说话极短。一次不超过一句，一句不超过十六个字。
- 不讲道理，只报事实：「云上来了」「这一势，按到腰」。
- 不催促、不夸奖、不卖萌。用户做不做，她都在那儿。

这套语气决定了整个作品的文案：**四层字，全部是短句**（势名 / 心解 / 白话 / 歌诀）。

## 三、造型

| 部位 | 设定 | 为什么 |
| --- | --- | --- |
| 整体 | 纯墨剪影，无五官 | 缩到 130 像素仍立得住；留白给想象 |
| 发 | 道髻一枚，鬓角一缕 | 一缕是为风留的，静止画面也要有动势 |
| 衣 | 交领道袍，广袖垂坠，腰带一道留白 | 广袖是十三势唯一能读出动作的地方 |
| 色 | 只有墨 `#1b1916` | 全画只有她和那一痕脊是实的 |
| 道具 | 无 | 有道具就变成角色，没有才是「看山的人」 |

十三势的姿态参数写在 `src/postures.ts`，每一势对应肩、肘、腰、膝四个自由度；
这是她的**动作库**，也是后续做动画、做手办、做表情包的原件。

## 四、她在作品里做什么

- 站在金顶岩台上，**不迎人、不看镜头**。
- 用户吸气，她随之上抬到这一势的 62%；用户呼气，她落势到底。
- 用户不按，她就站着（无极）。**她不主动表演**——这一点是设定，不是省事。

## 五、延展（落地用）

| 形态 | 用法 | 需要做什么 |
| --- | --- | --- |
| 竖屏装置 | 金顶排队区、紫霄宫数字厅 | 现成，直接部署 |
| 手机扫码 | 山门、索道站、门票二维码 | 现成，同一份构建 |
| 表情包 | 十三势 + 「云上来了」「再站一会儿」 | 从动作库导 16 帧 |
| 文创 | 十三势印章、香囊、折页 | 十三势名字已定，配图可用姿态剪影 |
| 数字藏品 / 会员权益 | 走完十三势发一张「朝元帖」 | 需要景区侧账号体系，本期不做 |

## 六、AI 创作溯源（对应赛事「溯源材料」要求）

| 环节 | 用了什么 | 留痕 |
| --- | --- | --- |
| 选题、文案、十三势释义 | 与 AI 助手逐轮讨论定稿 | 对话记录（提交时附截图） |
| 造型 | 影像是**代码画出来的**，不是生图 | `src/figure.ts` 全部参数与绘制逻辑 |
| 山、云、殿 | 程序化 + 固定种子 | `src/scene.ts`，种子 `0x5a17c0de` |
| 字体 | 思源宋体子集，567 字 | `scripts/subset-fonts.py` 可复现 |
| 未使用 | 没有用任何一键生成图片、没有用模板 | 仓库里没有任何贴图文件 |

**这一条要如实说**：作品的「AI 味」不在生图，在**协作**——选题、文字、结构、参数都是与 AI 一起推出来的，
最后落成可读、可改、可复现的代码。赛事禁止的是「纯一键生成的低质作品」，这份交付正好是它的反面。
