## 3. 创作说明（表单「作品说明」直接用，约 400 字）

武当山旧名太和山，金顶之上是太和宫；「七十二峰朝大顶」是它最有名的一句话。
《朝元》把这句话做成一个动作：**按住吸气，云从群峰倒流上金顶；松手呼气，云散回谷底。**

一口炁对应太极十三势中的一势——掤、捋、挤、按、采、挒、肘、靠、进、退、顾、盼、定。
每一势给出四层字：势名、十三势行功心解原文、为这座山写的半句白话、王宗岳《十三势歌》一句。
十三口气走完，十三个点亮起，画面收在「一炁朝元」。

全片只有一个交互手势，没有按钮、没有菜单、没有教程：看一眼就会，一只手就能完成。
它不解释武当，只让人**跟着呼吸走完一遍**——这是排队时最容易被浪费、也最容易被留下印象的三分钟。

视觉是一张纸上的版画：三层远山、一痕金顶、一个纯墨剪影的道童。没有一张贴图，全部由代码画出，
山脉与云的形状由固定种子决定，任何机器上都是同一座山。

## 4. 落地说明（这一项占 10 分，写全）

### 4.1 用在哪里

| 场景 | 具体位置 | 形态 | 解决什么 |
| --- | --- | --- | --- |
| 金顶排队区 | 太和宫下的等候平台 | 55 寸竖屏，2.5 米观看距离 | 旺季排队 40–90 分钟，游客无事可做、易烦躁 |
| 紫霄宫数字厅 | 宫内展陈动线末端 | 竖屏 + 耳机 | 看完展陈后需要一个「停一下」的收尾 |
| 太子坡研学 | 中小学生研学课程 | 平板 / 触屏一体机 | 太极不好讲，用呼吸把「十三势」讲成十三口气 |
| 索道轿厢 | 轿厢内小屏 | 竖屏循环 | 8 分钟车程正好一轮 |
| 线上 | 门票二维码、公众号菜单 | 手机浏览器 | 到不了武当的人也能走一遍 |

### 4.2 怎么上线（三步，都不需要改代码）

1. **拿到构建产物**：`npm run build`，`dist/` 只有 110 KB，可离线部署。
2. **放进装置**：把 `dist/` 拷到竖屏播放器或一体机，用浏览器全屏打开即可；断网也能跑。
3. **配置巡检**：装置侧只需要一条「心跳截图」任务（每天一张首屏截图），用于发现黑屏与字体缺失。

### 4.3 怎么衡量它有用（运营口径）

| 指标 | 口径 | 目标 |
| --- | --- | --- |
| 起势率 | 站到屏前 10 秒内按下过的人占比 | ≥ 55% |
| 完成率 | 走满十三势的人占起势人数的比例 | ≥ 12% |
| 单次时长 | 中位数停留 | 60–180 秒 |
| 扫码率 | 装置页脚二维码的扫码次数 / 起势人数 | ≥ 8% |
| 传播 | 收势页生成「朝元帖」的保存/分享次数 | 二期，需要账号体系 |

### 4.4 商业与延展

- **文创**：十三势印章（13 枚一套）、香囊、折页。名字与姿态已经定死，直接可做。
- **研学**：把「十三口气」做成 20 分钟课程包，配一张可打印的十三势图。
- **会员权益**：走完十三势发一张带日期的「朝元帖」（数字纪念，不做链上、不做二级交易）。
- **联名**：道茶、民宿、索道票面，用「一炁朝元」这一句做统一话术。

### 4.5 明确不做的（落地边界）

- 不做人脸识别、不采集生物信息：景区装置一旦采人脸，合规成本远超收益。
- 不做账号与支付：本期是展陈件，不是产品。
- 不做多语言：先把中文做到位。
