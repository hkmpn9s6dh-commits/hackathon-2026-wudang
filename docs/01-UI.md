# 01 · 界面（闸 A 第 1–4 节）

## 1. 风格预设

**纸上的版画，不是画在纸上的照片。**

- 底：宣纸暖白 `#faf6ec → #eee5d5`，一层 4% 的纸纹噪点，一层金顶上方极淡的暖光。
- 墨：`#1b1916`。远山三层，一层比一层实，山脚一律化进雾里（剪影**不许**有硬底边）。
- 朱：`#a33a2c`，只给三处用——左上角「朝元」印、山腰「太和」小印、十三格进度点。
- 金：`#b8894a`，只给金顶迎光的一侧和上方那抹天光。
- 字：思源宋体子集，一个字重。层级靠**字号与墨色**，不靠粗细。
- 留白：画面上方 40% 与下方 25% 基本是空的。空是内容，不是没做完。

## 2. 尺子（每件学哪一点）

| 尺子 | 学哪一点 | 不学什么 |
| --- | --- | --- |
| 《只此青绿》数字影像 | 色带的分寸：整块画面只允许一个彩色系，其余全部让给墨 | 不学它的青绿——武当是水墨，不是设色 |
| 故宫《清明上河图 3.0》 | 长卷的观看节奏：一段一段给，不一次倒完 | 不学它的投影与屏幕拼接 |
| teamLab《花与人》 | 触摸即变化：手一碰，画面立刻回应，中间没有按钮 | 不学它的高饱和与粒子海 |
| 《黑神话：悟空》小西天场景 | 造像与山体的体量感：人在景里必须小 | 不学它的 3D 写实 |
| 敦煌「数字藏经洞」 | 叙事顺序：先给氛围，再给字，最后给人 | 不学它的 UI 框架 |
| 武当山金顶实景 | 山脊线的实际形状：一侧陡、一侧缓，不是对称的锥 | 不学实景照片的灰 |

**共同结论**：这六件里没有一件是靠「信息多」赢的，都是靠**一个动作 + 一个画面**。

## 3. 记忆点（只有一个）

**那一线金顶。**

整幅画里只有脚下那块岩和一痕脊是实的、锋利的，其余全部化开。
人站在那一痕上，一动不动。观众记住的不是山，是「一个人站在一抹墨上」。

配套的记忆动作：**按住—吸气、松手—呼气**。一句话能复述，一只手能完成。

## 4. 主屏规格

| 项 | 值 |
| --- | --- |
| 主用比例 | 竖屏 9:16（景区竖屏 / 手机）；桌面按 16:9 横向延展，构图居中 |
| 题名 | 竖排，右缘，`clamp(40px, 6.4vmin, 76px)`，字距 0.18em |
| 势名 | 居中，`clamp(38px, 6.6vmin, 68px)` |
| 一句白话 | 势名下，`clamp(14px, 1.95vmin, 21px)` |
| 歌诀 | 最下一层，`clamp(11px, 1.45vmin, 15px)`，墨色 38% |
| 提示 | 页脚，字距 0.44em，3.6 秒呼吸动画 |
| 进度 | 十三根竖线，走完一根转朱色并拉长 1.5 倍 |
| 人 | 高度 `min(13.2vh, 40vw)`，站在画面 60% 高度处 |
| 边缘 | 左右各留 5.4vmin 以上；文字块永不越过竖排题名那一列 |

## 5. 已知弱项（先自己说）

1. 只有中文。赛道是国内赛，暂时够；出海要另做。
2. 人物是剪影，没有五官与表情；放大到全屏会显得简。
3. 十三势的姿态是参数化的近似，不是武术上的标准架；懂拳的人能挑出细节。
4. 云与雾是程序化的，长时间盯着看会发现循环。
5. 桌面宽屏下左右留白偏多，靠飞鸟与远山撑，撑不满 21:9。
