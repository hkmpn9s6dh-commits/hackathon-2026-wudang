# 06 · 复盘

## 一、这一场学到什么

### 1. 程序化的「细节」不等于「质量」

山改了四版。前三版都在加东西：五层剪影、近景松、石棱、岩台、叠墨、云海。
每加一层，画面更像"渲染"，也更像沙丘、棕榈、台子、飞碟——**它一直在变成别的东西**。

最后成立的是减法：一张纸、三层远山、脚下一小块岩、一痕脊、一个人。
判据很简单：**去掉这一笔，画面塌不塌？** 塌就留，不塌就删。

### 2. 「人站在地上」这个 bug，单测抓不到

人物一直浮在脊线上方。原因是 `drawFigure` 的坐标原点在头顶，而调用方传的是脚底，
差了整整一个身高。几何计算全对、类型全对、单测全绿——**错的是语义**。

抓它的是截图。所以：**验收一定要有一张自己看的图**，不能只有断言。

### 3. 量测会误报，要分清「矩形相交」和「视觉相压」

界面量测第一版报了 4 处「文字相压」：读数块占满整行宽（`left:0; right:0`），
矩形上与竖排题名相交，但文字是居中的，视觉上根本没碰上。
修法不是放宽判据，而是**让容器真的只占它该占的宽度**（`width: min(40rem, 56vw)`），
量测从此既严格又诚实。

### 4. 线上和本地是两次验收

`base: './'`、字体路径、`gh-pages` 的 `.nojekyll`——任何一处错，本地全绿、线上白屏。
所以 e2e 支持 `CHAOYUAN_URL`，同一套 23 项对线上再跑一遍。

## 二、留给下一场的三条

1. **先定「一笔」再写代码**：这一场如果先写下"全画只有一痕脊是实的"这句话，能省两小时。
2. **构图类改动一律先截图再改代码**：四版里有三版是改完才发现方向错的。
3. **文字分层用字号与墨色，不用字重**：中文单字重的版式更稳，也省掉一份字体文件。

## 三、与赛事规范的对齐

- 「禁止纯一键生成的低质量作品」：本作品没有一个像素是生成的，全部是代码画的；
  AI 参与在选题、文字、结构与参数上，且全过程留痕（`proof/trace/`）。
- 「提交溯源材料」：Prompt 摘录、可复现的参数层（`postures.ts` / `figure.ts` / `scene.ts`）、
  时间线三样齐备，改文案重跑 `subset-fonts.py` 即可复现字体。
